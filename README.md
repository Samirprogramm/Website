# Website

Static website project for a TechDucky / Ducky V1 product page.

## Overview

This repository contains a single-page website built with plain HTML, CSS and JavaScript. It is designed to be easy to host on GitHub Pages, Cloudflare Pages or any static web host.

## Files

- `index.html`: main website file.
- `assets/`: optional images and supporting files, when present.

## Run Locally

Open `index.html` in a browser, or serve the folder with a small static server:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deployment

Any static host can serve this project. Upload the files as-is or connect the repository to a static hosting provider.

## Notes

Keep product copy clear, avoid exposing secrets in frontend files and test the page on both desktop and mobile.
